Panduan: segerakkan data ke semua peranti (Firebase, percuma)

Laman ini dihoskan di GitHub Pages (fail statik), jadi data tidak boleh dikongsi antara peranti tanpa pangkalan data. Firebase Firestore (percuma) digunakan untuk itu. Panduan penuh dalam bahasa Inggeris: fail README.md dalam repositori GitHub anda.

  1. Cipta projek Firebase — pergi ke console.firebase.google.com › Add project. Matikan Google Analytics.
  2. Daftar apl web — ikon </> di halaman projek › Register app. Salin nilai firebaseConfig (apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId) ke dalam fail config.js.
  3. Cipta Firestore — menu Build › Firestore Database › Create database, pilih lokasi asia-southeast1 (Singapore), mod production. Kemudian tab Rules: tampal kandungan fail firestore.rules dan klik Publish.
  4. Aktifkan log masuk — Build › Authentication › Get started › Sign-in method › Email/Password › Enable. Tab Users › Add user: cipta e-mel dan kata laluan untuk kaunter.
  5. Benarkan domain — Authentication › Settings › Authorized domains › Add domain: masukkan domain GitHub Pages anda (cth. namaanda.github.io).
  6. Muat naik ke GitHub — muat naik semua fail (termasuk config.js yang telah diisi). Buka laman di setiap peranti dan log masuk sekali. Data lama dalam pelayar lama akan dimuat naik secara automatik.

Selepas siap, lencana di penjuru atas harus menunjukkan Cloud · segerak. Gunakan butang Uji sambungan di atas untuk semak.
